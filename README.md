# Real-Time Chat Application

A full-stack real-time chat application that enables users to communicate instantly through a responsive web interface. The application uses Socket.IO for real-time bidirectional communication between clients and the server.

## 🚀 Features

- Real-time one-to-one messaging
- Instant message delivery using Socket.IO
- Responsive chat interface
- User authentication
- Online/offline communication
- Persistent message handling
- Separate frontend and backend architecture
- REST API integration
- Real-time client-server communication

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- CSS
- Axios
- Socket.IO Client

### Backend
- Node.js
- Express.js
- Socket.IO
- MongoDB
- Mongoose
